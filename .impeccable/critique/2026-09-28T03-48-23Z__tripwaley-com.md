## Design Specificity Verdict
Authored, not interchangeable: ticket-stub rack, boarding-call itinerary, captain WhatsApp thread, fare board per boarding city, the 404, the curtain footer. The Trip Reel is strongest where the prop carries a fact. It fails where the reel was never edited: 8–12 set-pieces per page, many carrying no fact, and several inventing facts (seats left, live bookings, batch make-up, ratings) — which breaks PRODUCT.md principle 4. Detector: clean on shipped UI (exit 0); 119 sub-12px font sizes across 50 files are real and systemic because DESIGN.md's own label (0.64rem) and data (0.6rem) roles are that small. Lab bounce easing is sandbox-only; /lab and /lab2 404 publicly. Detector missed GSAP-string easings (elastic.out, back.out). Overlay injection impossible: browser pane blocks loopback from public origins (ERR_BLOCKED_BY_CLIENT), not CSP.
